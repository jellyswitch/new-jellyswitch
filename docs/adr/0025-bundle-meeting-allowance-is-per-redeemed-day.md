# A bundle's meeting-room allowance is per redeemed day, set by the operator

Alma Quiroga (Cowork Tahoe, 2026-08-06) booked 328 minutes of included rooms in one day on a 2-day bundle and was charged no overage: the bundle TYPE carried `included_meeting_room_minutes = 360` — the whole pack's pool (180 × 2) — while the charge math (`User#day_pass_reservation_charge_info`) has always scoped usage to a single day and compared it against the type's value. Every bundle SKU had the same shape (5-packs carried 900), so every bundle holder silently got `180 × pack size` free meeting minutes **per day**, and each new redeemed day reset it. We decided (David, 2026-08-07): **`included_meeting_room_minutes` on a bundle type is the DAILY allowance — the operator-set daily limit on room usage by non-members — identical in meaning to the field on a single day pass (which is inherently one day).** The math needed no change; the DATA did: a normalization migration rewrites exactly the `180 × quantity` pool pattern to `180` (custom values are left for operator review), and the operator forms now label the field "Included Meeting Room Hours (per day)". Usage beyond the daily allowance keeps billing overage at the location rate at booking time (ADR 0012) — the allowance limits free usage; overage pricing, the 240-minute per-booking cap, and posted-hours bounds (ADR 0023) limit the rest.

## Considered Options

- **Derive per-day = pool ÷ quantity in code, keep pools stored** — rejected: two representations of one number, divide edge cases on custom packs, and the operator can no longer read the field as the thing they set ("the daily limit").
- **A separate `daily_included_meeting_room_minutes` column for bundles** — rejected: schema growth for a semantic fix; single passes and bundle days already mean the same thing per day.
- **Hard-block bookings beyond the daily allowance** — not chosen here: exceeding the allowance bills overage (that's the Alma remediation), which both monetizes and deters; a hard daily stop remains available later if overage proves insufficient deterrence.
